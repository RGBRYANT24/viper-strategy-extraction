# 暴力枚举测试 - Winning/Losing 条件

这个测试脚本会暴力枚举所有井字棋的关键决策场景，测试你的PPO模型是否能正确处理获胜和防守的情况。

## 测试原理

### 1. 生成获胜案例（Winning Cases）
对于每个获胜组合（8种：3行+3列+2对角线），生成所有"X只差一步就能获胜"的棋局：
- 该获胜组合中有2个X，1个空位
- 在其余位置放置不同数量的O（0-3个）
- 确保棋局合法（X和O数量接近，且没有已经获胜的情况）

### 2. 生成防守案例（Losing Cases）
**不需要重新生成！** 只需将获胜案例的棋盘反转（X↔O）：
- 原来的"X差一步获胜" → 反转后变成"O差一步获胜"
- 此时X必须防守，否则下一步就会输

### 3. 测试模型
- 对每个案例，使用模型预测动作
- 检查模型是否选择了正确的关键位置
- 统计准确率并分析错误模式

## 使用方法

### 基本用法

```bash
# 测试默认模型
python evaluation/exhaustive_win_lose_test.py

# 测试指定模型
python evaluation/exhaustive_win_lose_test.py --model log/oracle_TicTacToe_ppo.zip

# 显示详细测试过程（包括所有失败案例）
python evaluation/exhaustive_win_lose_test.py --model log/oracle_TicTacToe_ppo.zip --verbose

# 调整失败案例显示数量
python evaluation/exhaustive_win_lose_test.py --model log/oracle_TicTacToe_ppo.zip --max-display 20
```

### 参数说明

- `--model`: 模型路径（默认: `log/oracle_TicTacToe_ppo.zip`）
- `--verbose`: 显示所有失败案例的详细信息
- `--max-display`: 当不使用verbose时，最多显示多少个失败案例（默认: 10）

## 评级标准

### 总体准确率评级
- **≥95%**: 优秀 ✓✓ - 模型在关键决策上表现出色！
- **≥85%**: 良好 ✓ - 模型在关键决策上表现良好
- **≥70%**: 及格 - 模型基本掌握关键决策
- **<70%**: 不及格 ✗ - 模型在关键决策上需要改进

## 测试案例数量

理论上，每个获胜组合可以生成多个测试案例：
- 8个获胜组合（3行+3列+2对角线）
- 每个组合有3个可能的空位
- 每个空位配合不同数量的O（0-3个）
- 每种O数量有多种放置方式（组合数）

实际生成的案例数量会根据合法性过滤有所不同，通常在100-200个左右。

## 与其他测试的区别

| 测试类型 | 覆盖范围 | 案例数量 | 用途 |
|---------|---------|---------|------|
| `evaluate_ppo_strategy.py` | 人工精选的战术场景 | ~10个 | 快速验证常见战术 |
| `exhaustive_win_lose_test.py` | **暴力枚举所有关键场景** | **100-200个** | **全面测试关键决策** |

## 建议

1. **训练后立即测试**: 在训练完成后运行此测试，评估模型的战术能力
2. **对比不同模型**: 使用相同的测试评估不同训练参数/算法的效果
3. **分析错误模式**: 关注错误分布，找出模型在哪些位置（行/列/对角线）容易出错
4. **结合对战测试**: 此测试关注关键决策，应结合对战测试（vs Random/MinMax）全面评估
