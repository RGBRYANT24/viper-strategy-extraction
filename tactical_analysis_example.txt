本报告分析每条规则的winning/losing条件。
对于每条规则，我们枚举所有有效的棋盘状态并检查：
  - Winning情况：玩家(X)可以一步获胜
  - Losing情况：玩家必须阻止对手(O)获胜
  - Critical情况：同时存在winning和losing条件

注意：我们只枚举count(X) == count(O)的棋盘，
      因为X是先手，我们正在决定X的下一步。

说明：

【规则约束棋盘】
- 显示规则的约束条件形成的棋盘模式
- X = 明确是自己的棋子
- O = 明确是对手的棋子
- . = 明确是空位
- ? = 完全未约束（可以是任何状态）
- ?/X = 不是对手（可能是空或自己）
- ?/O = 不是自己（可能是空或对手）

【具体示例棋盘】
- 显示符合约束条件的具体棋盘实例
- 每个棋盘都是从约束条件枚举出的合法状态
- 单行格式 (O..X.XXO.) 用于快速识别，0位置到8位置依次排列

如何解读：
1. 规则约束棋盘：展示这条规则覆盖的所有可能局面的**模式**
2. 有效棋盘数：根据约束条件枚举出的具体棋盘总数
3. Winning/Losing局面：分析每个具体棋盘的战术特征
4. 示例棋盘：展示几个典型的具体棋盘实例

理想情况：
- 正确获胜次数应该接近100%（总是选择获胜）
- 正确防守次数应该接近100%（总是选择防守）
- Critical情况需要权衡，优先获胜还是防守取决于具体局面

举例理解：
规则约束棋盘 = 规则的"模式"（比如"左上是对手，右下是对手，其他位置有部分约束"）
具体示例棋盘 = 符合这个模式的"实例"（比如"左上O，上中空，右上空，..."）
