# 决策树规则可视化工具使用说明

## 快速开始

### 生成给导师看的英文报告（推荐）

```bash
# 生成包含所有规则的完整报告
python export_rules_report.py

# 只包含前20条最重要的规则
python export_rules_report.py --max-rules 20

# 自定义输出文件名
python export_rules_report.py --output viper_policy_report.txt
```

生成的报告包含：
- ✓ 英文格式，适合给导师看
- ✓ 完整的棋盘状态可视化
- ✓ 动作优先级和概率分布
- ✓ 按重要性排序
- ✓ 统计摘要
- ✓ 可以直接用于论文/演示

### 自己查看分析（中文）

```bash
# 查看前10条规则摘要
python visualize_tree_rules.py

# 查看某条具体规则
python visualize_tree_rules.py --rule 1

# 交互模式（逐个查看）
python visualize_tree_rules.py --interactive
```

## 输出示例

### 棋盘显示格式

```
┌─────┬─────┬─────┐
│  O  │ ?/O │  ?  │  <- O=对手, ?/O=不是自己
├─────┼─────┼─────┤
│ ?/X │  ?  │ ?/X │  <- ?/X=不是对手, ?=未约束
├─────┼─────┼─────┤
│  X  │  ?  │  O  │  <- X=自己
└─────┴─────┴─────┘
```

**符号说明：**
- `X` = 自己的棋子（明确）
- `O` = 对手的棋子（明确）
- `.` = 空位（明确）
- `?` = 未约束（规则没提到这个位置）
- `?/X` = 不是对手（可能是空或自己）
- `?/O` = 不是自己（可能是空或对手）

### 动作优先级表

## 给导师的报告内容

运行 `python export_rules_report.py` 后，生成的报告包含：

### 1. 摘要统计
- 总规则数
- 优先级分布
- 动作分布统计
- 平均条件数

### 2. 每条规则详情
- 优先级分数（越高越重要）
- 支持样本数（训练时匹配的样本数）
- 棋盘状态（完整的3×3格子）
- 规则条件（可读格式）
- 动作优先级排序
- 有效性检查

### 3. 按重要性排序
规则按优先级从高到低排列，最重要的规则在前面。

## 典型使用流程

```bash
# 第1步：生成报告（给导师）
python export_rules_report.py --max-rules 20 --output policy_report.txt

# 第2步：自己先检查几条规则
python visualize_tree_rules.py --rule 1
python visualize_tree_rules.py --rule 2

# 第3步：查看报告
cat policy_report.txt
# 或者用编辑器打开
```

## 优势

与神经网络相比，这种可视化展示了VIPER的优势：

✓ **可解释性** - 每条规则都清楚地展示了决策逻辑
✓ **可验证性** - 可以人工检查策略是否合理
✓ **可理解性** - 不需要深度学习知识也能理解
✓ **可调试性** - 容易发现和修复问题

适合用于：
- 论文中展示策略学习结果
- 向导师解释模型行为
- 与MinMax等最优策略比较
- 调试和改进训练过程

## 注意事项

1. **优先级高的规则最重要** - 从这些规则开始看
2. **注意支持数** - 支持数高的规则更可靠
3. **检查警告信息** - 工具会自动标出潜在问题
4. **未约束位置(?)** - 表示规则对该位置没有要求
