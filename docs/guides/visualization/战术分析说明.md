# 决策树规则战术分析工具

## 功能说明

这个工具对决策树规则进行深入的战术分析，通过**枚举所有可能的合法棋盘状态**来检查每条规则的战术特征。

### 核心功能

1. **约束枚举**
   - 对于每条规则，根据约束条件枚举所有可能的棋盘状态
   - 正确处理不确定的位置（`?/X`, `?/O`）
   - 只枚举合法的棋盘（count(X) == count(O)，因为X先手）

2. **战术分析**
   - **Winning情况**: 玩家(X)可以一步获胜的棋盘数
   - **Losing情况**: 玩家必须阻止对手(O)获胜的棋盘数
   - **Critical情况**: 同时存在winning和losing条件的棋盘数

3. **策略评估**
   - 检查规则的最佳动作是否正确选择了获胜位置
   - 检查规则的最佳动作是否正确选择了防守位置
   - 计算正确率

## 使用方法

### 基本用法

```bash
# 分析所有规则
python analyze_rules_tactical.py

# 只分析前10条规则（测试）
python analyze_rules_tactical.py --max-rules 10

# 指定输出文件
python analyze_rules_tactical.py --output my_tactical_report.txt
```

### 完整示例

```bash
# 1. 先分析前5条规则看看效果
python analyze_rules_tactical.py --max-rules 5 --output test_tactical.txt

# 2. 查看结果
cat test_tactical.txt

# 3. 如果结果正常，分析所有规则
python analyze_rules_tactical.py --output full_tactical_analysis.txt
```

### 棋盘格式说明

工具显示**两种棋盘**：

#### 1. 规则约束棋盘（模式）

显示规则的约束条件：
```
       ┌─────────┬─────────┬─────────┐
       │    O    │   ?/O   │    ?    │
       ├─────────┼─────────┼─────────┤
       │   ?/X   │    ?    │   ?/X   │
       ├─────────┼─────────┼─────────┤
       │    X    │    ?    │    O    │
       └─────────┴─────────┴─────────┘
```

**约束符号说明：**
- `X` = 明确是自己的棋子
- `O` = 明确是对手的棋子
- `.` = 明确是空位
- `?` = 完全未约束（可以是任何状态）
- `?/X` = 不是对手（可能是空或自己）
- `?/O` = 不是自己（可能是空或对手）

这个棋盘展示规则的**模式**，一眼就能看出规则关注哪些位置。

#### 2. 具体示例棋盘（实例）

显示枚举出的具体棋盘状态：

**单行格式**（快速识别）：`O..X.XXO.`
- 9个字符依次表示位置0到8

**二维格式**（详细显示）：
```
       ┌───┬───┬───┐
       │ O │ . │ . │
       ├───┼───┼───┤
       │ X │ . │ X │
       ├───┼───┼───┤
       │ X │ O │ . │
       └───┴───┴───┘
```

**状态符号说明：**
- `X` = 玩家的棋子
- `O` = 对手的棋子
- `.` = 空位

这些棋盘是符合约束条件的**具体实例**，用于战术分析。

## 关键概念

### 1. 有效棋盘枚举

对于约束中的不确定位置，工具会枚举所有可能：
- `?/X` (不是对手): 枚举为空(0)或自己(X)
- `?/O` (不是自己): 枚举为空(0)或对手(O)
- `?` (未约束): 枚举为空(0)、自己(X)或对手(O)

**重要约束**: 只保留 count(X) == count(O) 的棋盘，因为：
- X是先手玩家
- 现在轮到X下棋
- 所以双方棋子数量必须相等

### 2. Winning条件

一条获胜线上有：
- 2个己方棋子
- 1个空位

此时在空位下棋就能获胜。

### 3. Losing条件

一条获胜线上有：
- 2个对手棋子
- 1个空位

此时必须在空位下棋阻止对手获胜。

### 4. Critical情况

同时满足：
- 存在至少一个获胜位置
- 存在至少一个防守位置

这是最复杂的局面，需要做出战术选择。

## 解读结果

### 理想的规则特征

1. **高Winning率**: 说明规则覆盖了很多进攻机会
2. **高Losing率**: 说明规则覆盖了很多防守需求
3. **高正确率**:
   - 正确获胜次数/Winning局面 应该接近100%
   - 正确防守次数/Losing局面 应该接近100%

### 潜在问题标识

1. **低正确获胜率** (<80%): 规则可能没有选择最优的获胜动作
2. **低正确防守率** (<80%): 规则可能忽略了防守需求
3. **高Critical率** (>20%): 规则经常面临既能赢又需防守的两难局面

## 性能提示

- 枚举所有可能的棋盘状态是指数级复杂度
- 对于约束少的规则，可能需要枚举数千个棋盘
- 建议先用 `--max-rules 10` 测试
- 分析全部50条规则可能需要几分钟

## 技术细节

### 约束解析

```python
# <= -0.5  -> 对手(O)
# > 0.5    -> 自己(X)
# > -0.5 AND <= 0.5 -> 空位(.)
# > -0.5   -> ?/X (不是对手，可能是空或自己)
# <= 0.5   -> ?/O (不是自己，可能是空或对手)
# 无约束   -> ? (任意)
```

### 枚举约束

只枚举满足以下条件的棋盘：
1. 每个位置的值符合约束
2. count(X) == count(O)
3. 没有已经分出胜负

### 战术检查

对每个枚举的棋盘：
1. 检查8条获胜线
2. 找出可以获胜的位置
3. 找出必须防守的位置
4. 检查规则的最佳动作是否匹配
