# 决策树测试脚本使用说明

## 概述

`test_trees.py` 脚本用于批量测试VIPER训练的决策树模型,对战以下对手:
- **MinMax**: 理论最优的井字棋对手
- **神经网络**: 使用MaskablePPO训练的神经网络策略

## 已配置的模型文件

脚本中已经硬编码了以下6个决策树模型:

```python
TREE_MODELS = [
    "viper_mask_ppo_tree_20251106_225702_iter10_samples100_depth10_leaves50.joblib",
    "viper_mask_ppo_tree_20251106_225739_iter10_samples4000_depth10_leaves50.joblib",
    "viper_mask_ppo_tree_20251107_001324_iter10_samples50000_depth10_leaves50.joblib",
    "viper_mask_ppo_tree_20251107_003010_iter10_samples50000_depth15_leaves100.joblib",
    "viper_mask_ppo_tree_20251107_003045_iter10_samples50000_depth15_leaves150.joblib",
    "viper_mask_ppo_tree_20251107_003345_iter10_samples50000_depth10_leaves150.joblib",
]
```

神经网络模型路径: `log/oracle_TicTacToe_ppo_aggressive.zip`

## 在服务器上运行

### 基本运行 (测试所有对手)

```bash
# 进入项目目录
cd /path/to/viper-verifiable-rl-impl

# 激活环境
conda activate viperenv  # 或 source activate viperenv

# 运行测试 (默认每个对手1000局)
python test_trees.py
```

### 快速测试 (减少测试局数)

```bash
# 每个对手只测试100局 (用于快速验证)
python test_trees.py --n-episodes 100
```

### 只测试对战MinMax

```bash
python test_trees.py --no-neural-net
```

### 只测试对战神经网络

```bash
python test_trees.py --no-minmax
```

### 指定模型文件目录

```bash
# 如果模型文件在其他目录
python test_trees.py --directory /path/to/models/
```

### 完整的测试 (高精度)

```bash
# 每个对手测试5000局，获得更准确的结果
python test_trees.py --n-episodes 5000
```

### 文件输出

测试结果会自动保存到: `tree_evaluation_results.txt`

该文件包含详细的统计信息,包括:
- 每个模型的参数配置
- 对战每个对手的完整统计(平均奖励、标准差、胜/平/负次数和比率)

## 性能评估标准

### 对战MinMax (理论最优对手)

- ✅ **优秀**: 平局率 ≥ 85% (接近最优策略)
- △ **良好**: 平局率 70-85%
- ✗ **需改进**: 平局率 < 70%

> 注意: 对战MinMax几乎不可能获胜,平局是最好的结果

### 对战神经网络

- ✅ **优秀**: 胜率 ≥ 15% 且平局率 ≥ 80%
- △ **良好**: 胜率 5-15% 且平局率 70-80%
- ✗ **需改进**: 负率 > 20%

## 结果解读

### 参数含义

- `s{N}`: samples - 训练样本数量
- `d{N}`: depth - 决策树最大深度
- `l{N}`: leaves - 决策树最大叶子节点数

### 预期结果

1. **样本数量的影响**:
   - samples=100: 性能较差,可能有明显漏洞
   - samples=4000: 性能有所提升
   - samples=50000: 性能最佳

2. **树复杂度的影响**:
   - depth=10, leaves=50: 较简单的树,可解释性好,性能一般
   - depth=15, leaves=100-150: 更复杂的树,性能更好,但可解释性下降

3. **对手难度**:
   - MinMax最难 (理论最优)
   - 神经网络次之 (强但非最优)

## 运行时间估算

- 每个模型对战MinMax: ~30秒 (1000局)
- 每个模型对战神经网络: ~1-2分钟 (1000局)
- 总计6个模型: **约10-15分钟** (1000局/对手)

如果增加到5000局/对手,总时间约 **50-75分钟**

## 故障排查

### 模型文件不存在

```
✗ 模型文件不存在: viper_mask_ppo_tree_xxx.joblib
```

**解决方法**:
- 确认模型文件在当前目录下
- 或使用 `--directory` 参数指定模型目录

### 神经网络模型加载失败

```
✗ 模型加载失败: ...
```

**解决方法**:
- 确认 `log/oracle_TicTacToe_ppo_aggressive.zip` 存在
- 如果路径不同,修改脚本中的 `NEURAL_NET_MODEL` 变量

### 内存不足

如果服务器内存有限,可以:
1. 减少测试局数: `--n-episodes 100`
2. 分批测试: 使用 `--no-neural-net` 或 `--no-minmax`

## 后续分析

测试完成后,你可以:

1. **查看最佳模型**: 根据输出的"最佳模型"部分选择性能最好的树
2. **提取决策规则**:
   ```bash
   python -c "
   import joblib
   from sklearn import tree
   model = joblib.load('最佳模型文件.joblib')
   rules = tree.export_text(model)
   print(rules)
   "
   ```
3. **可视化决策树**: 使用 sklearn 的 `plot_tree` 功能

## 快速开始 (推荐命令)

```bash
# 1. 快速验证 (100局)
python test_trees.py --n-episodes 100

# 2. 标准测试 (1000局)
python test_trees.py

# 3. 高精度测试 (5000局, 用于最终评估)
python test_trees.py --n-episodes 5000 > test_results.log 2>&1 &
```

最后一条命令会在后台运行并将输出保存到 `test_results.log` 文件中。
